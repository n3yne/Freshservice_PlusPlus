Navigation

The page loaded when opening a new tab or when the app starts for the first time. Until you set one, it is the start page of the first site plugin (such as Freshservice).

When the app starts, reopen the tabs that were open when it last closed. Turn it off to start on the Home URL instead. Pinned tabs always come back.

Appearance & Features

Switch between the default dark color scheme and a light color scheme.

Show the panel on the right side of the window. Plugins add their tabs to it, such as Notes from Note Backup and Solutions from Solutions Chat.

Keep the side panel's tabs on one row and scroll through them with the arrow buttons or the mouse wheel. Turn it off to wrap the tabs onto more rows so they are all visible.

Updates

When a new version is out, download it in the background and install it the next time you close MSP++ (or right away from the notification). Turn this off to be asked before anything downloads. MSP++ checks when it starts and every 6 hours.

Site Permissions

A site in a tab has to ask before it uses your microphone, camera, location, notifications or clipboard, or opens a link in another program. Your Allow or Block answer is remembered for that site. Forget the saved answers to be asked again.

Plugins

Manage installed plugins. Each plugin also has its own tab below with its settings and the same on/off switch. Turning a plugin on or off takes effect after restarting the app.

Restart the app to apply plugin changes.
