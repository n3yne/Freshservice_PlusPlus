Navigation

The page loaded when opening a new tab or when the app starts for the first time. Until you set one, it is the start page of the first site plugin (such as Freshservice).

When the app starts, reopen the tabs that were open when it last closed. Turn it off to start on the Home URL instead. Pinned tabs always come back.

Put a dot on a background tab when its page changes on its own, such as a new reply changing the page title. The dot goes when you switch to the tab.

Put a coloured stripe along the top of tabs open on a site, such as Freshservice or ConnectWise Manage, so you can tell them apart at a glance. Pick each site's colour below.

Appearance & Features

Switch between the default dark color scheme and a light color scheme.

Show the panel on the right side of the window. Plugins add their tabs to it, such as Notes from Note Backup and Solutions from Solutions Chat.

Keep the side panel's tabs on one row and scroll through them with the arrow buttons or the mouse wheel. Turn it off to wrap the tabs onto more rows so they are all visible.

Updates

When a new version is out, download it in the background and install it the next time you close MSP++ (or right away from the notification). Turn this off to be asked before anything downloads. MSP++ checks when it starts and every 6 hours.

Site Permissions

A site in a tab has to ask before it uses your microphone, camera, location, notifications or clipboard, or opens a link in another program. Your Allow or Block answer is remembered for that site. Forget the saved answers to be asked again.

Move Settings to Another PC

Export your settings to a file, then import it in MSP++ on the other PC. The file has your app and plugin settings, bookmarks, canned responses and which plugins are on. API keys are left out: enter them again on the other PC. Notes, timers and other plugin data aren't included. Importing replaces the settings on this PC, except for its saved API keys.

Plugins

Installed shows the plugins you have, grouped by what they do. Browse lists more plugins you can install from the MSP++ plugin directory. Turning a plugin on or off, installing, updating or removing one all take effect after restarting the app.

Restart the app to apply plugin changes.

Plugins can read the pages and tickets you open, use your saved API keys and run code on this PC, the same as MSP++ itself. Only install plugins you trust. Every download is checked against the directory's checksum before it's unpacked.

MSP++ checks the plugin directory 30 seconds after it starts and once a day. With this on, updates for your plugins download by themselves and apply the next time you start MSP++. With it off, they're listed here and in the notifications.
